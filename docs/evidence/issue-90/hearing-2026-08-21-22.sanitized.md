# Issue #90 / #91 聞き取り記録（匿名化済み）

issue #90（価格改定支援）・issue #91（棚卸し除外品）のコメント欄で行った owner 聞き取りの質問と回答を記録する。回答の意味、業務ルール、判断理由は維持し、店舗・取引先の識別につながる固有名詞だけを一般化した。値上げ連絡の差出人となる問屋は「主要問屋 A（手芸用品の問屋、メーカー兼業）」、カタログ改版で混乱が生じたメーカーは「手芸用具メーカー B」と表記する。数値・業務ルール・判断理由は原文のまま記録する。

## #90 第 1 陣（2026-08-21）

### 1. 端数の切り捨て・切り上げに店主側の基準があるか

**回答:** 棚卸しの見方ではメーカーは小数点以下切り捨てが多い。店の切り売りで出る端数は切り上げ。伝票は気にする — 仕入原価が違えば修正する。

### 2. 値上げ連絡 1 回あたりの対象商品数

**回答:** バラバラ。1 品のこともあれば、店で扱わない商品も含めて 400 品程度のこともある。

### 3. 上乗せ商品の新売価の決め方

**回答:** その都度決める。値上げ連絡の新売価が上乗せ分まで上がっていた場合、リストどおりにしてさらには上げないこともある。

### 4. 掛率推定の暫定原価と伝票確定原価を後から見分けたい場面があるか

**回答:** 値上げ後も在庫が減らず新規仕入が発生していない商品は存在する。棚卸しは「今店にある在庫の原価合計」で在庫ゼロはカウントしない。店頭在庫があれば未仕入でも改定後（推定）の原価でカウントする。質問後半は意図が伝わらず未回答（→ 第 2 陣 Q1 で再質問）。

補足として、売れるが古すぎて棚卸しカウントから外している商品があり単品コードを使わないという実態が第 1 陣の回答中に surfaced し、issue #91 起票の契機になった。

## #90 第 2 陣（2026-08-22）

### 1. 電卓で出しただけの原価と伝票で確かめた原価を紙で書き分けたことはあるか

**回答:** あるが、伝票と見比べて PC の棚卸しリストの原価欄を直接書き換えたこともある。

### 2. 値上げ連絡の差出人と仕入先の関係

**回答:** 差出人は主要問屋 A の営業。店が仕入れる手芸用品メーカー全ての値上げ・廃番（製造中止）連絡はすべて主要問屋 A を経由する。値上げ連絡は手芸用品のみで、ヘア雑貨・エプロン・バッグ等は在庫が売れて同じものを再仕入したときの伝票で知る。原価・売価の修正は仕入のタイミングのみ。

### 3. 掛率は取引先ごとに一律か

**回答:** 商品により違う。

### 4. 新商品を置くとき掛率から原価や売価を決める場面があるか

**回答:** 新商品に限らず手芸用品の伝票には掛率をもとに売価設定基準になる参考上代が書いてあり、基本はそのとおりに消費税をのせたもの。原価は問屋が指定するもので店が決めるものではない。ただし「約定」があり、セールスと直に仕入の相談をして例えば毛糸を全色仕入れる場合、基準の原価より安くしてくれることがある。ヘア雑貨は参考上代がないものがあり、原価から店が決めるものがある。

## #90 第 3 陣（2026-08-22）

### 1. 値上げ連絡リストの商品の書かれ方

**回答:** バーコード・商品名・メーカー品番・旧売価・新売価は必ず書いてある。カタログ発行元はカタログページを表記する場合もある。店のどの商品か探すのは簡単。ただし手芸用具メーカー B はカタログページを書いておらず、商品リニューアルでバーコード・メーカー品番まで変わり、商品名がそっくりな用途別・デザイン違いの複数品があるため対象品か混乱することがある。同社の新カタログは毎年届くが廃止品リストは来ていない。

### 2. 仕入先の社数

**回答:** 直接の問屋・メーカーは 5 箇所程度。問屋経由で手芸用品 43 社、それ以外 31 社。廃業・権利譲渡・統廃合が進んでおり、商品があっても取引先が潰れたという連絡は問屋経由で来る。今ないところも含む。

### 3. 値上げ連絡から売価変更までの時期

**回答:** 先に分かる場合とセールスから遅れて来る連絡もある。取扱い数の多いものは他の作業をしていない限り優先してやるが、指定日までわざわざ待つことはしない。店の都合で商品により作業が遅れることはある。

### 4. PC 画面の客からの可視性

**回答:** PC 画面を客に見せるのはメーカーサイトのカタログを見せるときだけ。普段は操作している自分の背面が壁。現状困ることはない。（キャスター付き作業台があれば移動しながら値付け替えや棚卸しカウントが楽、という補足あり）

### 5. 転記作業の期間

**回答:** 今回は量が多く、分ける意志がなくとも紙の棚卸しリストへの転記に 1 週間かかった。そこから PC への転記は 2〜3 日。

## #91 未確認事項 1〜4（2026-08-22）

### 1. 除外品の POS 売り方

**回答:** 部門キー（現レジ最大 20 程度）+ 金額で登録。単品コードのように「この商品が売れた」とは分からない（店主の記憶のみ）。バーコードがないだけで商品に問題がなければ部門キーで販売する場合がある。

### 2. 除外の基準

**回答:** 年数ではなく原価の根拠の有無。伝票保管義務（以前 5 年、今は 7 年）の範囲外で伝票が廃棄され原価を確認できないもの、取引先に聞いても既に取扱いがなくデータのないもの、バーコードのないもの、見た目が販売に適さないもの。約 4 年前に税理士から原価合計の問い合わせがあった際、保管伝票を 1 枚ずつ全件確認して選別した。

### 3. 復活

**回答:** ある。売れ残りが急に売れ、在庫が尽きて再仕入が必要になったとき新売価・新原価で復活させる。

### 4. 規模

**回答:** 今年 4〜5 点（多い方）、例年 1〜2 点。

## 確定事項への反映

### #90（issue コメントで確定済み）

- 掛率は導出値、永続化しない（専用カラム・専用ページなし。一括改定画面で 現原価 ÷ 現売価 を導出表示）
- 掛率由来の新原価（案）は小数点以下切り捨て
- 改定対象は在庫ゼロ商品を含む
- 新売価は店主の手入力、自動提案ロジックなし（新売価 × 現掛率 = 新原価案 の提示のみ）
- 暫定フラグ（推定原価/確定原価の区別カラム）は追加しない
- 絞り込み軸は「取引先（メーカー）・部門」。`suppliers`（取引先マスタ）の意味は「メーカー/ブランド = 値上げ連絡の主体」に固定し、問屋（発注チャネル）は保持しない。schema 変更なし、docs で意味を明記（design doc への反映は Plan Packet で）
- 取引先の登録経路は A 案 = `find_or_create_supplier` の公開 CMD 化 + フォーム inline 追加。約 80 社の事前一括投入はしない。既存商品の紐付けは一括改定画面で取引先を選んだ文脈で行確定したとき `supplier_id` 未設定なら同時に紐付ける漸進補完
- 事前入力・指定日反映は不要
- 中断・再開は行単位確定方式で成立（draft テーブルなし）。「最近改定した行」目印は price_history.changed_at から導出
- SP-103-04（商品一覧の原価列）: 顧客可視の制約はないため原典どおり原価列追加の方向を推奨（最終判断は Plan Packet）
- ② 入庫時原価差分検出は手芸用品以外の唯一の価格改定導線のため ① と同格の Tier A
- 店主の売価 = 参考上代の税込額（`selling_price` は税込）。税変換補助は設けない
- 次工程: Plan Packet 起草（SP-102-08 復活起票 + 機能設計 ①②③ + 取引先 A 案 + 原価列判断 + 90-traceability 再生成）→ Codex 発注
