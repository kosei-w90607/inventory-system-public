# Balanced Profile

Use for scoped implementation, routine coordination, focused diagnosis, and review where the relevant boundaries are already known.

- Keep decomposition compact and connect each step to the requested outcome.
- Reuse established repository patterns and verify the touched boundary.
- If an unresolved dependency would change the result, surface it instead of inventing a default.
- Escalate to broader synthesis only when the scoped evidence is insufficient.
