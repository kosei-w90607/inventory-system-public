# High-throughput Profile

Use for bounded search, inventory, classification, mechanical checks, and concise evidence collection.

- Require a narrow scope and explicit output shape.
- Return compact, structured evidence with file or command anchors.
- Do not infer missing policy, resolve an owner decision, or coordinate a complex state transition unless explicitly assigned.
- Hand ambiguous or cross-cutting findings back for broader synthesis.

Apply the [shared contract](../gpt-5.6-shared.md) without modification.
